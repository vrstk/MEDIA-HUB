# Media Hub

Независимое Android-приложение (Kotlin / Jetpack Compose / Material 3).

**Текущий этап: Milestone 0 — bootstrap.** Это ранний исходный код, а не полностью готовый продукт.

## Уже есть
- Русский интерфейс, 4 вкладки, тёмная и светлая темы.
- Реальный просмотр локальной папки Android через Storage Access Framework с сохранением разрешения, открытием файлов и созданием папок.
- Контракты облачных провайдеров и Room entities как основа архитектуры.
- Проверяемая политика передачи: исходник MOVE не может быть удалён без подтверждения и проверки содержимого.
- GitHub Actions для `testDebugUnitTest` и `assembleDebug`.

## Ещё не реализовано
- Google Drive OAuth, Mail WebDAV, двусторонний перенос и очередь задач.
- Загрузка архивного seed в Room (исторические метаданные остаются вне APK).
- Веб-импорт, распознавание похожих лиц, синхронизация.
- Защищённое хранение облачных учётных данных (данная версия их не запрашивает).

## Сборка
- JDK 17, Android SDK API 36, Android Gradle Plugin 8.13.2, Gradle 8.13, Kotlin 2.4.21.
- Откройте репозиторий в Android Studio, синхронизируйте Gradle и соберите `app:assembleDebug`.
- В CI используется `gradle/actions/setup-gradle@v4`, Gradle 8.13. Отсутствие закоммиченного Gradle Wrapper пока является задачей bootstrap.
- APK после **успешного** запуска Actions доступна в разделе Artifacts соответствующего запуска.

## Безопасность
Не вводите пароли и токены в Issues и Actions. Приложение не сканирует хранилище без выбранной пользователем папки. Оригиналы не удаляются автоматически.

Пакет-спецификация `Media_Hub_Project_Pack_v1.0.zip` является отдельным локальным исходным материалом. Персональный каталог и пользовательские файлы не помещаются в публичный репозиторий.
